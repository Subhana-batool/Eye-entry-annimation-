## ✨ Features

- 👁️ Interactive eye-based entry experience
- 🖱️ Press-and-hold interaction
- 📱 Mobile touch-and-hold support
- 👀 Animated pupil and eye blink
- ⭕ Hold-progress indicator
- ✨ Smooth reveal transition
- 🎨 Minimal and premium visual design
- 🏠 Responsive Home page
- 📩 Inquiry section
- 📱 Responsive desktop and mobile layout
- ♿ Keyboard-accessible site entry
- ⚡ Lightweight front-end implementation
- 🎯 Refined micro-interactions
- 🔤 Typography-focused design
